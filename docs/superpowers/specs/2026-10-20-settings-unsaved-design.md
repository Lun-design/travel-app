# UX-15B 行程設定未儲存保護

使用者已確認：日期、每日出發時間、時區修改後取消／系統返回需確認；主題及通知維持立即生效。

- 保護範圍僅四個儲存欄位。基準取本次開啟時的資料，改回基準可直接關閉。
- 同一 Modal 的底部確認列顯示繼續編輯／放棄修改，不建立巢狀 Modal。放棄只捨棄尚未儲存欄位，不撤回主題與通知。
- 介面說明主題與通知立即生效，不需儲存；確認列同樣提醒立即設定不受放棄影響。
- 同帳號／行程背景刷新不覆蓋輸入，關閉重開及切換帳號／行程才重新初始化。
- 使用同步鎖避免重複儲存與儲存中關閉；session token 阻止舊成功／失敗結果更新新表單或卸載後更新狀態。
- 原日期／時間／時區驗證、callback payload、主題與通知 handler 保留。失敗顯示原後端訊息並保留輸入。
- 不新增 DB、持久化草稿或整頁離站／重整攔截。不變更權限、登入或同步資料流。

驗證：四欄 dirty 判定、取消與返回確認、繼續／放棄、背景刷新、scope切換、快速連點、延遲成功／失敗、立即設定不計入dirty及不被復原，另跑既有時區回歸與全套測試／型別／建置。
