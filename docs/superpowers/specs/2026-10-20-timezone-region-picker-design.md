# UX-11：中文時區地區選單

日期：2026-10-20。使用者已確認以下最小改動方案；已完成本機驗證（957 項測試、TypeScript、build、verify:build）。尚未提交／部署／實機驗收。

- CreateTripModal（新增／編輯）及 TripSettingsModal 使用同一個 TimezonePickerField。
- 常用地區以中文城市標籤選擇，值仍為既有 IANA 字串；美國以紐約／洛杉磯分列，夏令時間由 IANA 規則處理，不寫死 UTC offset。
- Web 使用原生 select，Native 使用可收合選項清單，點擊範圍至少 44px。保留其他／進階 IANA 輸入；進入進階不先覆蓋目前值；既有非清單合法值原樣顯示與儲存。
- 新增／編輯行程保留手動判定入口；只有使用者點擊才根據目的地提出可辨識時區。無法判定或只有多時區國家時保留原值並提示選城市。不因目的地輸入或背景資料更新自動判定。
- 手動判定是保守本地建議，不是 Geocoding。若已知城市／對應國家詞移除後仍有未知地名或其他文字，回傳無法判定，避免加拿大 London 等同名城市誤判；不擴充成全球地名搜尋。
- 仍沿用父表單驗證與 onSave／onCreate／onUpdate。選擇僅更新表單 timezone，取消不寫入；不改景點時間、日期、分帳或同步機制，不加 DB 欄位。
- 表單長度增加時保留可捲動內容與可達操作列，儲存中停用時區選擇。
- TDD 覆蓋對照、既有自訂值、進階切換、無效值阻止儲存、手動判定、不動其他時間欄位與原回呼；跑全量測試、type-check、build、verify:build。
