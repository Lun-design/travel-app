# 手機時間軸閱讀修整

使用者已核准截圖檢討提出的方向：頂部減層、卡片全寬閱讀、小狗素材防黑白底、FAB 縮小，並在顯示層處理完全重複備註。不包含日期吸頂。

## 不變條件

不修改資料庫、原始備註、時間、圖片 URL、交通計算、同步及權限。原有票券、跳今天、旅途模式、地圖、照片大圖／更換、景點選單、跨天移動、導航均保留。同步錯誤／離線／待同步／可復原提示不可被收納掩蓋。桌面保留既有功能展示方式。

## 顯示設計

1. 手機將當日票券／跳今天、旅途模式及地圖開關放入預設收合的「旅程工具」；子元件維持掛載。地圖內容保持原顯示狀態，不改原地圖偏好。工具狀態按 trip/day 隔離；空白引導、行前資訊及重要警示保持可見。單行摘要可水平瀏覽完整預算資料，不刪數據。
2. 完全同步時移除獨立橫列，改放在 Header 既有文字區的小狀態；其他同步情境保留完整 Banner、重試及衝突處理。
3. 手機卡片上方為縮圖＋標題資訊，下方地址、備註、導航不再受縮圖欄限制。桌面沿用圖片在左、內容在右。保留縮圖點擊層與各選單回呼。
4. 原始 `-6.gif`、`-8.gif`、`-10.gif` 經逐幀 RGBA 分析確認含不透明黑／白底。導航使用真正透明的 `journal-reading.gif`（讀地圖情境），以 28px 裁切顯示容器放大原圖有效區域，不編輯 GIF、不使用 mix-blend，不將同一個分類圖片硬套為透明。其他來源及頭像不變。
5. 只有與標題完全相同、或與「原時間＋標題」完全相同的備註行不重複呈現。保留其他原文及額外資訊；不寫回資料庫、不因部分包含標題而刪除。單獨有意義的相近描述仍顯示。
6. 手機 FAB 為 48px「＋」，保留「新增景點／活動」無障礙名稱與原回呼；桌面維持文字。原 144px 底部可捲留白不縮減。這會減少遮擋面積，但不宣稱懸浮鈕不可能遮住任何中途內容；仍需手機實測。

## 驗證

新增工具 disclosure、全寬卡片版型、完全同步分流、備註去重及透明導航素材回歸。先 Red 再 Green；全量 test、type-check、build、PWA 及 diff check。獨立唯讀審查；不能用 style 單元測試宣稱完成真實視覺驗收。不自動 git 提交／部署，無 migration。
