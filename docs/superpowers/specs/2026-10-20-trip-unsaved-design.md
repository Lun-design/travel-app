# UX-15A 行程表單未儲存保護

使用者已同意先限定新增／編輯行程，不加入持久化草稿。

- 修改後取消或系統返回，留在同一個 Modal 顯示「繼續編輯／放棄修改」。未修改或改回原值直接關閉。
- 繼續編輯保留全部欄位；放棄才關閉，下次開啟從最新 props 初始化。
- 同一帳號／行程的背景刷新不重設正在編輯的內容；切換帳號、行程或重新開啟才初始化。
- 儲存成功直接關閉；失敗保留輸入與錯誤。儲存中禁止重複提交與關閉。
- 原時區、日期、建立／修改 callback 與 payload 保留，不新增 DB migration，不將表單內容宣稱為已同步或已保存草稿。
- 測試涵蓋上述互動、六個欄位的 dirty 判定、scope 切換、延遲儲存結果與原有時區回歸。

不涵蓋瀏覽器整頁返回／重整攔截、持久化草稿、個人資料與行程設定表單。
