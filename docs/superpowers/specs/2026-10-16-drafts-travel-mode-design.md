# 草稿保護、旅途模式、時區標示與手機表單

使用者已核准；新增可選功能，不改寫既有行程順序/時間/完成狀態，不修改 DB Schema。

- 草稿覆蓋景點、費用、票券新增及票券 metadata 編輯。關閉髒表單提供繼續、保留草稿、放棄；重開先詢問恢復，禁止自動覆蓋。帳號/行程/表單/record 隔離，本機七天 TTL，沿用登出清理前綴。只存文字/JSON，不存附件；提示需重選檔案。明確區分本機草稿與雲端儲存。
- 舊草稿基準若不同於最新 record 的可編輯欄位，禁止直接恢復，提示丟棄舊稿後重新編輯。瀏覽器重整/離開採原生 beforeunload，頁面隱藏同步落盤；平台限制儲存時顯示錯誤但仍保留關閉確認。API 成功清稿，失敗不清；舊請求不得清除新草稿。
- 下一站模式預設關閉，手動開啟/上一站/下一站/退出，選取日依既有 position 順序，僅改當前檢視 ID。顯示該站資訊、目的地導航及精確綁定票券；空清單/末站/刪除站點有邊界保護。
- 時區只顯示文字，不轉換 time 或日期。明確標記台灣/日本/韓國時間者優先，其餘顯示依行程時區，不依航班目的地猜測出發時間。應用於時間軸、旅途模式、集合快捷資訊與表單。
- 三類表單共用鍵盤避讓、可捲動內容與固定底部操作列，Web visualViewport 輔助鍵盤避讓；Safe Area 不遮末欄，取消/儲存至少44px。
- 測試：草稿 TTL/隔離/衝突/失敗/成功刪除/頁面離開；手動切站不改資料與導航/票券；時區數值不變；表單底部內容與回歸互動；全套 Vitest/tsc/Web build。
