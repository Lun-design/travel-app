# 行程頁資訊收納：第一階段

使用者核准以精簡主畫面與資訊收納降低頂部佔用；此波限三項，不變更資料邏輯。

1. TripDetailHeader改為返回、行程名稱／日期摘要、搜尋及行程選單的緊湊導覽。裝飾縮小，窄螢幕不搶文字空間。旅伴頭像／全部旅伴／個人資料／邀請／分享／主題／主人設定收進選單，沿用原callback與權限。
2. TimelinePanel移除獨立大型DAY Hero，日期分頁與原更多行程操作併為一列。DayTabs新增dense選項（其他用法預設不變）；日期、當前Day、選取狀態及原切日callback保持。
3. 行前準備與住宿／集合資訊收進一個TripTravelInfo可展開區，預設收合，另保留住宿／集合快捷入口，一鍵展開內部重要資訊。隱藏內容仍掛載、保持原資料訂閱與編輯狀態；帳號／行程切換重設收納狀態。

安全邊界：不改Supabase/API、同步、排序、照片、地圖預設與導航。OfflineSyncBanner、錯誤、衝突及空白行程引導不放進收納區。此波不加入桌面側欄、捲動自動隱藏或sticky日期列。

UI要求：44px點擊、標明展開狀態，選單可按關閉／遮罩／系統返回離開；收合內容不攔點擊、不進入閱讀器。長名稱需裁切而非擠掉搜尋／選單，寬窄螢幕皆保留入口。

驗收：新舊旅伴與主人權限、選單開關與callback、Day切換、重要資訊快捷展開與不重掛載、背景刷新與scope切換；完整測試、type-check、build、PWA；盡可能做手機／桌面視覺檢視，無法實測需明示。
