# 旅程便利體驗：核准規格

使用者已核准四項漸進功能；保留完整編輯、匯入、邀請、導航、離線與復原流程。

1. 新增景點預設簡易模式：名稱、天數；更多設定保留地址、時間、費用、類別、營業時間與備註。編輯既有資料時完整展開。新增可儲存並繼續，成功才清空，保留天數與插入位置的遞增，失敗保留輸入。同步 ref 防連點。
2. 可收合行前總覽：打包完成度與本機尚未離線票券數。實際讀取帳號/行程隔離快取，不以遠端 metadata 猜測。載入、讀取失敗、平台不支援均明確顯示；可開清單/票券。
3. 本機重要資訊：從現有景點明確選擇住宿/集合點，帳號與行程隔離保存釘選 ID，不改寫或複製景點。顯示最新時間/地址，一鍵複製、導航與分享（不帶私人備註）。清楚標示本機偏好；景點刪除後忽略不存在 ID。
4. 空行程顯示新增第一站、匯入、邀請，空單日提供當日新增。保留原 FAB/選單入口；不強制教學。

所有新區塊採可收合、暖咖啡色、44px 點擊目標、手機自動換行。非同步讀取加過期回應保護、失敗不造成白畫面。票券檔案仍僅在目前裝置保存，登出既有清理有效。

驗收：新增/編輯與連續新增；打包/離線快取統計與失敗狀態；釘選隔離與導航/分享；空白入口；全套測試、type-check、Web build。
