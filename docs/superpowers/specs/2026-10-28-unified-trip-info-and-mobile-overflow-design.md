# 行程頁常用資訊整合與手機溢位修正

## 目標

精簡行程頂部，讓住宿、集合和一般常用地點收在唯一的「常用資訊」入口中，避免使用者沿長時間軸尋找地址；同時修正手機日期籤與摘要列的裁切。

## 設計

- 移除「旅程資訊」內的行前準備卡片。打包、票券功能仍保留在原有打包清單與預約／票券分頁，不刪除資料或行為。
- 時間軸上方只顯示一張小狗主題的「常用資訊」入口。入口摘要顯示目前釘選筆數；點擊開啟底部資訊面板。
- 面板內以純文字標籤區分住宿、集合與常用地點，每筆直接顯示名稱、地址和導航操作；複製／分享收在次要操作。雲端同步說明、Day／時間／時區等非找地址必要資訊不佔每筆主要版面。管理入口沿用現有權限和選擇行程景點流程。
- 既有住宿／集合釘選資料全部保留，新增 `place` 通用釘選類別，最多 12 筆仍套用於整份常用資訊清單；以資料庫 migration 更新既有 kind 約束。
- 手機摘要列改為可換行且不裁切的緊湊佈局，縮短費用標籤，避免藏起需要橫向滑動才能看到的行程統計。
- 日期籤自動定位使用固定卡片步距，避免結尾日期因水平捲動邊界而只露出部分標籤；日期、選取狀態與切日回呼不變。

## 不變範圍

不變更行程、景點、打包清單或票券資料；不改權限、導航 URL、分享內容的私人資料排除規則、每日選擇、路線計算、狗狗素材或主色。資料庫 migration 只擴充可接受的 pin kind，不刪除或重寫既有列。

## 驗證

依工作區本回合限制，不新增或執行測試。執行 TypeScript type-check、正式 Web build、PWA build-output 驗證及 `git diff --check`。無可用手機瀏覽器時明確標示未完成實機視覺驗收。
