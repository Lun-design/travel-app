# Supabase Auth Flow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增 Email 登入／註冊頁、驗證提示、重寄驗證信與根路由 Auth Gate。

**Architecture:** `lib/auth.ts` 封裝 Supabase Auth 與中文錯誤映射；`AuthGate` 管理 session 狀態與路由導向；`login.tsx` 負責表單與未驗證提示。首頁保留行程功能並加入登出。

**Tech Stack:** Expo Router、React Native、Supabase Auth、TypeScript、Vitest。
